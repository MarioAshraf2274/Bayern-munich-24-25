# ⚽ FC Bayern Munich Performance Analytics (2024-25) 
An end-to-end, enterprise-grade Power BI Data Analytics and Performance Engineering Solution evaluating FC Bayern Munich's competitive output across the 2024-25 season. This project transforms unstructured match data and granular player-level logs into an interactive, decision-ready analytics dashboard built upon a clean Star Schema relational architecture.
To explore the full visual interface, interactive slicers, and dynamic cross-filtering capabilities, you can watch the LinkedIn Demo Video.
🎯 Business Problem and Analytical Objectives
Modern sports analytics requires converting raw event logs into actionable tactical intelligence. The primary objective of this project is to provide coaching staff, analysts, and sports executives with an integrated analytical hub to evaluate key aspects of team performance:
The analysis focuses heavily on Offensive Output Efficiency by tracking goal generation, assist distribution, and normalized involvement per minute played. It also addresses Squad Age and Depth Dynamics through detailed evaluation of positional distribution, age profiles, and rotation metrics across tactical roles. Furthermore, the dashboard examines Venue and Opponent Sensitivity by evaluating Home versus Away performance variance and identifying defensive vulnerabilities against specific opponent tactical setups.
🔄 Data Pipeline and Transformation Workflow
Before establishing the relational model, raw datasets underwent rigorous extraction, cleaning, and structuring within Power Query using the M language. The initial phase involved handling missing values, standardizing team and player naming conventions, and removing duplicate records.
Strict data typing was enforced across all fields, converting text inputs into proper integers, decimals, dates, and strings. Unpivoting techniques were applied to convert raw logs into normalized row structures within the main row-level data table. Finally, surrogate and foreign keys were generated to link player profiles seamlessly with match occurrence logs and seasonal totals.
🏗️ Data Architecture and Star Schema Modeling
The semantic data model utilizes a strict Star Schema architecture optimized for high-performance query execution and DAX measure evaluation.
The architecture is built around core dimension and fact tables:
The DIM PLAYERS dimension table serves as the primary lookup repository containing descriptive player metadata such as player name, age, nation, and tactical position. The FACT PlayerSeason table functions as a granular fact table storing aggregated seasonal statistics per player, including goals, assists, playing time, and 90-minute equivalents.
The Fact matches table captures match-level operational details, including fixture dates, competitions, rounds, venues, and opponent names. The Table ROW Data BAY table acts as an underlying normalized source table tracking row-level events. Finally, the dax measures table is an isolated measure container hosting all DAX business logic, ensuring model maintainability and a clean project structure.
🧮 Comprehensive DAX Logic and Business Metrics
All analytics logic is encapsulated within the dedicated dax measures table. Key performance metrics implemented in the model include:
Total goals aggregates overall squad scoring output, while Total Assists tracks total assist contributions. Goal Contributions combines both metrics to reflect overall offensive output, complemented by total GA for tracking total goal involvement across all matches.
Playing time and appearance metrics are measured through Total minutes and Player matches. Normalization metrics include cotrib per match, which calculates average goal involvement per match appearance, and Mins per goal, which evaluates scoring rate efficiency. Additional calculated metrics include mins per contribution, measuring minutes required per goal or assist, and percent of team goals, which evaluates an individual player's contribution ratio relative to the squad's total scoring output.
Squad demographics and venue performance are handled via avg.age for positional age tracking, as well as Home Win percent and Away Win percent for evaluating venue victory rates.
🎨 Design System and Visual Layout
The dashboard incorporates a custom Dark Glassmorphic Theme designed for high contrast and visual clarity. The interface features a custom metallic crimson header integrating official club branding alongside distinct executive KPI cards displaying total goals, assists, overall contributions, and total minutes played.
Interactive Player and Opponent slicers enable real-time cross-filtering across all visual elements. The visual mapping comprises dynamic bar and column charts for Top 5 Goal Scorers, Top 5 Assists, and Goals Conceded by Opponent, paired with positional breakdowns, squad age distributions, and venue win percentages via interactive donut visuals.
